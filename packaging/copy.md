# Hotspots

## Tagline

Trace, tag, and export interactive image hotspots.

## Description (3 sentences)

Hotspots is a browser-based editor for drawing clickable regions on top of any image. Trace shapes with a pen tool, name them, add links or arbitrary key/value tags, and export a self-contained interactive HTML file.

## Origin Story

I wanted to author clickable regions for fun websites and little image-based stories, and kept running into issues with how to relate the different layers. Hotspots sticks it all together with exportable assets.
